Flow Mode keeps browsing anchored: following a link within a site reuses the current tab instead of
opening a new one. Links to a different site still open separately.

The point is fewer stray tabs, and a clearer sense of where you actually are.

## How to use it

1. Turn it on with the switch above.
2. Browse normally — there's nothing else to configure.
3. Turn it off if you'd rather every link open its own tab.

## Notes

Experimental, and personal to you — it doesn't affect anyone else on the account.

Desktop browser extension only. The Kindredly browser on a phone already keeps each site in its own
view, so there is nothing for Flow Mode to do there.

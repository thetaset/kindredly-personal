Kindredly Companion is a small desktop app that keeps browser protection in place on a computer.
The browser extension can be removed from inside the browser, and private browsing gets around it;
Companion sits outside the browser and closes both.

## How to use it

1. Install it on the child's computer — there are macOS, Windows and Linux builds on the
   **Download** page.
2. It pairs with the browser extension rather than replacing it.
3. It asks for the current Unlock PIN before it will let a protected setting change.

## Notes

Experimental. No parental control is completely effective — a determined or technical child may
still find a way around it, and none of this replaces staying involved.

Its counterpart on phones is [Kindredly Guard](/features/kindredly-guard).

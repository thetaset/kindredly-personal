Content filtering checks pages as they load and blocks adult content, suggestive themes and
profanity. It's the layer underneath everything else, including Library Mode.

## How to use it

1. Open **Family**, pick the person, then **Content blocking & filtering**.
2. Pick a strictness level — **Strict**, **Moderate** or **Relaxed**. **Custom** opens the
   individual settings.
3. Set **Image censoring** if you want images scanned too.
4. Use **Rules** for family-wide blocked sites, category rules and image scanning.

## Notes

Filtering can't be turned off for a restricted child — the server turns it back on.

Image scanning runs on the device, so nothing is uploaded to be checked. It's slower on low-end
hardware.

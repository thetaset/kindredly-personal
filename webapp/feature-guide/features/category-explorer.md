Category Explorer sorts your library into subject groups — science, cooking, history — and matches
items on your own device. Nothing is sent anywhere to be sorted.

An item can sit under more than one subject, and nothing has to be filed to be findable.

## How to use it

1. Open **Library → Categories**.
2. Tap a topic to see what matches. The badge shows how many.
3. Toggle **Hide empty** if the grid looks sparse.
4. Switch category sets to view the same library a different way.

## Settings

**Category Sets** manages the sets and which one is active. The link above opens it.

This one is family-wide, so it applies to everyone on the account and only a parent or admin can
change it.

AI Chat is an assistant built into Kindredly that you can talk to, by typing or by voice.

## Notes

Not switched on for families yet, so there's nothing to turn on today. This page is here so you
know it's coming.

It will be a Plus feature, and it's still experimental.

Kids won't get it unless a parent turns it on for them, and it will be off for everyone until
somebody does.

This is not the same as the **AI** slot in Default Apps, which sends "Ask AI" to whichever outside
assistant you choose. That works today; this is ours, and doesn't.

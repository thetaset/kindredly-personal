Kindredly Guard is a small app for a child's phone. It reports which apps they're using and for how
long, and enforces the limits you've already set — so a time budget covers their phone, not just
their browser.

## Notes

**Android is experimental.** You can turn it on and set it up today, but it is early access and not
generally released — expect rough edges, and don't rely on it as the only thing standing between a
child and their phone.

**iPhone is coming soon.** It waits on Apple's approval for the permissions it needs.

It is a Plus feature, and it links to a child's account from **Family** — a phone has to be enrolled
by a parent, not by the child.

Limits you set under [Usage limits](/features/usage-limits) are the same limits Guard enforces;
there isn't a second set to keep in step.
